# 249_stitch — GitHub Pages Store

A static ecommerce-style storefront for 249_stitch, designed for GitHub Pages.

## Files
- `index.html` — page structure
- `style.css` — responsive design
- `script.js` — products, filters and cart
- `assets/logo.png` — supplied 249_stitch logo

## Change products
Open `script.js` and edit the `products` array.

## Change prices
The starter price is `950.99 EGP` based on the information provided. Change `price: 950.99` if your intended price is different.

## Add real product photos
Replace the placeholder `.product-image` areas in `index.html`/`script.js` with your own image paths.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Go to Settings → Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save.

GitHub will provide the public Pages URL.

## WhatsApp checkout
In `script.js`, replace `YOUR_NUMBER` in the commented WhatsApp line with your international phone number, without `+`, spaces or dashes, then uncomment the `window.open(...)` line.
